## 财年支持

选择器使用 `range(datetime.now().year - 5, datetime.now().year + 3)`；2026 年显示 2021–2022 至 2028–2029，默认 2025–2026。主机跨年会变化，选项不代表税法版本。

| 财年 | 支持边界 |
| --- | --- |
| 2025–2026 | 主要回归和既往授权报表验收年度，普通个人旧制折扣模型；不保证涵盖所有特殊税务事实 |
| 2021–2022 至 2024–2025 | 可筛选并重放历史库存，没有独立年度规则表，未逐年验证全部例外 |
| 2026–2027 | 可试算，代码无条件提示政策未验证；不等于法律本身全部未知 |
| 2027–2028、2028–2029 | 有选项，未实现改革后规则，不能按旧模型最终申报 |
| 其他/特殊历史资产 | 未确认完整支持；pre-CGT、1999 前指数化等未实现 |

所有财年都没有个人所得税及 Medicare 计算。

## 已知缺口与未验证边界

1. 转仓仅全局持仓检查；零/无效数量只记明细，不一定使结果不完整，不能称自动核实。所有权变化仅提示，未计算其实际市值处置。
2. 不采集居民/临时居民、实体、投资用途或豁免；50% 不通用。FIFO 是软件策略，不是法律唯一强制批次法。
3. **Stake 非 BUY/SELL/已知转仓类型会跳过**，公司行动支持弱于 Nabtrade，未保证完整提示；关键字段缺失的非卖出行可能被 dropna 排除。后续独立修复任务应补回归，本轮不改。
4. Nabtrade 没有独立去重；Stake 跨文件 ID/指纹机制仍有账户缺标识及复杂分笔/重叠报表误判风险。转仓不改库存不等于账户级配对/去重保证。
5. 未识别公司行动主要提示，不保证将相关历史批次成本标为未知。漏掉调整可能令后续小计仍不准确；`cost_known` 只覆盖已识别路径。
6. BSP 成本分配/持有期、一般重组 rollover、拆并股、不等量行动等不完整。调整记录日期是来源日期，不能视为已确认税法取得日。
7. 缺完整成本要素/调整账本及 AMIT，ETF CGT 仍可能受影响。无汇率来源与日期证据；没有自动外汇换算。
8. 审计覆盖卖出、已读买入、转仓和处理过的行动，不是所有原始行的不可变存储；CSV 无规则版本/输入哈希。期初亏损手工输入，历史未核实事项可能影响该余额。
9. 金额用浮点，无统一法定舍入契约；同日真实时序无法跨报表恢复。缺性能/压力、可访问性、损坏文件、广泛 `.xls` 和真实海外验收。
10. 依赖未全锁定；启动检查依赖 Streamlit 内部协议。开发容器现有命令关闭 CORS/XSRF，不应复制为生产安全配置，本轮未改。

`is_complete` 仅表示代码未捕获到所列问题，不证明全部税务事实正确。
