# 澳洲股票 CGT 清算

应用以本次修改前可运行的 `f5054cc` 为基础，保留原来的单文件 `app.py`、页面布局、两个券商 Excel 上传入口和全局 FIFO 历史匹配流程。

## 使用

上传 Nabtrade 和/或 Stake 的原始 Excel，选择财年，点击原来的“开始融合账目并计算”即可。无需账户映射、转仓配对或补充证据 CSV。

侧栏只有两个可选补充项：普通券商转仓的受益所有权确认、往年尚未使用资本亏损（默认 0）。不确认转仓所有权仍会显示计算小计，但不会把未验证的假设说成最终报税结果。原表若明确所有权变化，不会被总确认覆盖。

保留原版兼容性：未提供的可选费用列和空白费用按零、无交易关键字段的页脚/汇总行不进入买卖流水，同日多笔成交按稳定的报告记录顺序执行 FIFO，不再一律拦截。请核对该顺序符合你的批次选择。

## 修正的计算问题

- 部分卖出同步扣减剩余买入手续费，避免重复抵扣。
- 资本亏损先抵扣不享受折扣的盈利，再抵扣长期盈利，最后应用个人 50% 折扣。
- 财年包含 6 月 30 日全天；持有期限按日历周年判断，排除买入/卖出日。
- Stake 空白交易编号不再全部变为同一个 `nan`；相同文件/重叠报表保留重复成交的出现次数。
- 不同市场的同名证券不共享库存。
- 普通转仓仅检查全局历史库存，不生成买卖、不重置购入日期及成本；不要求另行建立券商账户账本。
- 缺失原始成本的股票不再被写成零盈利；列出问题，并继续展示其他有完整记录股票的小计。
- 不把明确的外币单价当作 AUD。Nabtrade 国际交易需原表中的 AUD 单价；Stake Wall St 可提供 Currency=AUD 或明确的 AUD 价格/费用列。缺失时列入待核对，不影响其他澳股的小计。
- 资本返还不按金额大小猜测总额/每股金额；明确提供 `Capital Return Per Share (AUD)` 时调整成本并记录超出成本的利得，否则只标记相关股票待核对。

有缺失、解析问题、未核对所有权或未验证财年政策时，结果明确标为“非最终报税金额”。具体原因直接显示，不再只给出笼统红色校验失败并拦截整份结果。可下载已知交易逐批次 CSV。

本工具计算股票/ETF 交易 CGT，不计算工资、股息、利息或个人全部所得税；年度 ETF 成本调整及其他公司行动仍须核对。原版 50% 个人折扣模型用于符合条件的个人；2026-27 及以后政策未核验时仅显示待核对小计。
