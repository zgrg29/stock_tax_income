# 澳洲股票 CGT 清算

应用以本次修改前可运行的 `f5054cc` 为基础，保留原来的单文件 `app.py`、页面布局、两个券商 Excel 上传入口和全局 FIFO 历史匹配流程。

## 使用

上传 Nabtrade 和/或 Stake 的原始 Excel，选择财年，点击原来的“开始融合账目并计算”即可。无需账户映射、转仓配对或补充证据 CSV。

侧栏只有两个可选补充项：普通券商转仓的受益所有权确认、往年尚未使用资本亏损（默认 0）。不确认转仓所有权仍会显示计算小计，但不会把未验证的假设说成最终报税结果。原表若明确所有权变化，不会被总确认覆盖。

保留原版兼容性：未提供的可选费用列和空白费用按零、无交易关键字段的页脚/汇总行不进入买卖流水，同日多笔成交按稳定的报告记录顺序执行 FIFO，不再一律拦截。请核对该顺序符合你的批次选择。

## 修正的计算问题

- 部分卖出同步扣减剩余买入手续费，避免重复抵扣。
- 资本亏损先抵扣不享受折扣的盈利，再抵扣长期盈利，最后应用个人 50% 折扣。
- 财年包含 6 月 30 日全天；持有期限按日历周年判断，排除买入/卖出日。
- Stake 空白交易编号不再全部变为同一个 `nan`；相同文件/重叠报表保留重复成交的出现次数。
- 不同市场的同名证券不共享库存。
- 普通转仓仅检查全局历史库存，不生成买卖、不重置购入日期及成本；不要求另行建立券商账户账本。
- 同一证券在 Nabtrade 的 `.ASX`、`.AXW`、`.CXA` 等市场后缀和 Stake 的无后缀代码统一识别；`TRANSFER_OUT` / `TRANSFER_IN` 与空格形式按同一转仓类型处理。
- 每笔卖出逐批计算；某笔记录待核对不会删除整个 ticker 已匹配的盈亏。未匹配数量单独说明，已算出的金额保留为试算，不能把未知部分当零盈利。
- 不把明确的外币单价当作 AUD。Nabtrade 国际交易需原表中的 AUD 单价；Stake Wall St 可提供 Currency=AUD 或明确的 AUD 价格/费用列。缺失时列入待核对，不影响其他澳股的小计。
- 资本返还不按金额大小猜测总额/每股金额；明确提供 `Capital Return Per Share (AUD)` 时调整成本并记录超出成本的利得，否则只标记相关股票待核对。

有缺失、解析问题、未核对所有权或未验证财年政策时，结果明确标为“非最终报税金额”。具体原因直接显示，不再只给出笼统红色校验失败并拦截整份结果。

所有识别到的原始卖出在匹配和币种检查之前保留，显示财年内及财年外记录、重复/解析失败/币种待换算等状态；不能计算盈亏也不会从页面消失。每行处理失败只影响本行，不再截断整张工作表后续成交。支持查看及下载全部卖出、已匹配批次的买入成本/手续费/卖出收入，以及已读入的历史买入记录。支持 SALE/SELL 和 PURCHASE/BUY 等明确类型、同市场常见交易所前后缀，跨券商代码规范一致；日期字符串按澳洲日/月/年解析，Excel 日期和 ISO 日期保持原义。

同一文件内重复编号可能是分笔成交，原始行保留并提示；跨文件仅在编号/出现次数指纹及全部成交内容一致时去重。相同编号、不同成交内容不会直接删除。

本工具计算股票/ETF 交易 CGT，不计算工资、股息、利息或个人全部所得税；年度 ETF 成本调整及其他公司行动仍须核对。原版 50% 个人折扣模型用于符合条件的个人；2026-27 及以后政策未核验时仅显示待核对小计。

## 增持与公司行动

- DRP（红利再投资）和 SPP（购股计划）使用发行日、数量和报表实际分配/认购金额建立独立批次；有 Value 时优先使用实际金额，避免显示单价的舍入误差。
- 免费获配权利按原表明确的零金额记录；配对的权利行权以权利原成本加实际认购款建立新股批次，购入日为行权日。随后临时代码转正式代码只承接批次，不重复计算认购款。
- `CHANGE_SECURITY_CODE`、`RECONSTRUCTION` 等按同日、同报表账户、相同数量的一正一负记录配对；保留原始批次。报表中随行结转的原费用不再次收取。一般重组的 rollover 条件仍须核对，未默认所有重组都免税。
- `BSP` 赠股和不明确的持仓调整会保留增持数量，并标注原股/新增批次的成本待核对，不把报表估值或分红参数擅自当成税务成本。相关批次若在目标财年出售，数量仍匹配，但未知盈亏保留为空并提示，不能按零成本计算。
- 历史已平仓的待核对事项与未来未出售持仓的成本问题，保留在公司行动明细，不直接删掉目标财年其他资产的已匹配利润。需要核对的当前年度税务事件仍会使结果标为试算。

规则参考：[ATO 红利再投资](https://www.ato.gov.au/law/view/pdf/pbr/td2000-003.pdf)、[ATO 权利行权](https://www.ato.gov.au/forms-and-instructions/capital-gains-tax-guide-2021/whats-new/investments-in-shares-and-units/exercising-rights-or-options-to-acquire-shares-or-units)、[ANZ 赠股计划说明](https://www.anz.com/content/dam/anzcom/shareholder/bonus-option-plan-terms-and-conditions.pdf)。
